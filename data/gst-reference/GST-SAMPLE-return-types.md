# GST Return Types

## GSTR-1 — Statement of Outward Supplies
Reports all sales invoices, credit/debit notes, and outward supply details for the period. Filed monthly (11th of next month) or quarterly under QRMP (13th of month after quarter-end). Buyers can only claim ITC on invoices after the seller files GSTR-1.

## GSTR-3B — Summary Return
A self-declared summary return reporting total sales, purchases, ITC claimed, and net tax payable — this is the return through which tax is actually paid. Filed monthly (20th) or quarterly under QRMP. Cannot be revised once filed; corrections happen in a later period's return.

## GSTR-2A / GSTR-2B — Auto-drafted Purchase Statements (read-only, not filed)
- **GSTR-2A**: dynamic, updates continuously as suppliers file their GSTR-1.
- **GSTR-2B**: static, generated monthly — the primary document used to verify ITC eligibility before filing GSTR-3B. ITC should be claimed only when it appears in GSTR-2B.

## GSTR-9 — Annual Return
Consolidates the financial year's monthly/quarterly returns. Mandatory for regular taxpayers with turnover above ₹2 crore (optional below that). Due 31st December following the financial year.

## GSTR-9C — Reconciliation Statement
Reconciles audited financial statements with the GST annual return figures. Applies above ₹5 crore turnover. Filed alongside GSTR-9, same due date.

## Composition scheme returns (different track)
Composition dealers file **CMP-08** quarterly and **GSTR-4** annually instead of GSTR-1/GSTR-3B.
